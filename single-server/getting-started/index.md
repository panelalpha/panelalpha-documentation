# Getting Started

This section helps you go from installation to stable daily operations.
It focuses on practical steps and production readiness.

## Section Scope

In this section you will:
1. Install PanelAlpha on a single server.
2. Access Client Area and Admin Area for the first time.
3. Secure panel access with SSL.
4. Apply updates safely.
5. Enable additional user languages.

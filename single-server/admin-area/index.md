# Admin Area

The Admin Area is the operational center for platform administration.
Use it to monitor instances, manage users, review logs, and configure global platform behavior.

## Pages In This Section

- [Dashboard](dashboard.md)
  Operational overview with widgets for instances, activity, and platform health.
- [Instances](instances.md)
  Manage all client WordPress instances, templates, and SSL certificates from one place.
- [Services](services.md)
  Manage the default service and its instances, domains, and hosting accounts.
- [Users](users.md)
  List platform users, shared-access users, and per-user activity logs.
- [Logs](logs.md)
  Search and filter activity, task, server, and diagnostic logs.
- [Migrations](migrations.md)
  Monitor, retry, and manage website migrations and imports.
- [Notifications](notifications.md)
  Review platform alerts, operational warnings, and system events.
- [General](configuration-general.md)
  Control global panel behavior: URLs, localization, security defaults, and SEO.
- [Default Plan](default-plan.md)
  Define default hosting limits, backups, updates, and permissions for new services.
- [Server](server.md)
  Monitor server health, firewall, WAF, mail, and IP management.
- [Automatic SSL](automatic-ssl.md)
  Configure automatic SSL providers, orders, and logs for managed domains.
- [Plugins & Themes](plugins-and-themes.md)
  Manage plugin packages, theme categories, and custom assets.
- [Integrations](integrations.md)
  Configure third-party integrations like SSL, analytics, and preview URLs.

# Integrations

PanelAlpha connects to a range of third-party services to extend analytics, SSL automation, onboarding, preview URLs, and collaboration. This section lists each integration and how to enable it for your platform.

## Pages In This Section

- [Atarim](atarim.md) — Visual feedback and task management on live WordPress sites
- [AWStats](awstats.md) — Built-in visitor and bandwidth statistics from server logs
- [Matomo](matomo.md) (DEPRECATED) — Legacy analytics integration replaced by the internal statistics tool
- [Google Analytics](google-analytics.md) — Track and report website traffic with Google Analytics
- [Let's Encrypt](lets-encrypt.md) — Automatic SSL certificate generation for instances
- [Google PageSpeed Insights](google-pagespeed-insights.md) — Measure webpage loading speed and capture screenshots
- [DB-IP](db-ip.md) — Geolocation integration to identify logins from new devices
- [Extendify](extendify.md) — AI-powered Super Quick Onboarding and one-step website creation
- [10Web](ten-web.md) — AI-powered WordPress website creation for Super Quick Onboarding
- [WithoutDNS](withoutdns.md) — Temporary preview URLs for websites before DNS propagation
- [Fastly](fastly.md) — Edge CDN with cache purge, Under Attack Mode, and Fastly DNS records in Set Your Domain
- [Stripe](../direct-billing/stripe.md) — Direct Billing for trial and paid plans (see also [Direct Billing](../direct-billing/index.md))

# Client Area - Instances

The Client Area is where end users create and manage their WordPress instances. This section covers the full instance lifecycle, from listing, creating, and importing through details, domains, DNS, sharing, monitoring, backups, plugins, and advanced settings.

- [Plugins](plugins.md) — Install, update, and manage WordPress plugins with bulk actions
- [Advanced Settings](advanced-settings.md) — Configure security, auto updates, Git, developer tools, and copy instances

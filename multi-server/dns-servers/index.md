# DNS Servers

DNS servers let PanelAlpha manage zones and records for your WordPress instances. This section covers each supported DNS provider and how to connect it to your plans so clients can use the DNS Zone Editor.

## Pages In This Section

- [Cloudflare](cloudflare.md) — Configure Cloudflare as a DNS server and manage zones and proxy settings
- [Bunny.net](bunny.md) — Configure Bunny.net as an external DNS provider for PanelAlpha Engine setups
- [cPanel DNS Only](cpanel-dns-only.md) — Configure cPanel DNSOnly as a dedicated DNS server
- [PowerDNS](powerdns.md) — Configure PowerDNS, synchronize zones, and set up DNS templates

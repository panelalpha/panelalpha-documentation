# Onboarding Methods

Onboarding methods define how end users create new WordPress instances in PanelAlpha. Choose between Standard, Quick, and Super Quick workflows depending on how much control or speed you want to offer during site creation.

## Pages In This Section

- [Quick Onboarding](quick-onboarding.md) — Fast instance creation with theme selection and subdomain automation
- [Super Quick Onboarding](super-quick-onboarding.md) — Fastest onboarding using Extendify or 10Web AI-powered creation
- [Standard Onboarding](standard-onboarding.md) — Full-control onboarding recommended for advanced users

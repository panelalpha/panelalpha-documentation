# Client Area - Hosting

The Client Area Hosting section lets end users manage hosting-level resources for their services. It covers everything from the service summary and domains through FTP/SFTP access, databases, cron jobs, files, DNS zones, and email management.

## Pages In This Section

- [Summary](summary.md) — View hosting service summaries, plan usage, and instance details
- [Domains](domains.md) — Add, edit, or remove domains and configure SSL settings
- [FTP Accounts](ftp-accounts.md) — Create and manage FTP accounts with quotas and directory access
- [SFTP Accounts](sftp-accounts.md) — Create and manage secure SFTP accounts over SSH
- [MySQL Databases](mysql-databases.md) — Manage MySQL databases, users, and phpMyAdmin access
- [Cron Jobs](cron-jobs.md) — Create and manage cron jobs to automate scheduled tasks
- [File Manager](file-manager.md) — Browse, upload, and manage files in table or grid view
- [DNS Zone Editor](dns-zone-editor.md) — Add, edit, and delete DNS records for your domains
- [Email Addresses](email-addresses.md) — Manage email accounts, webmail access, and SPF/DKIM records
- [Email Forwarders](email-forwarders.md) — Set up and manage email forwarders between addresses

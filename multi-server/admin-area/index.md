# Admin Area

The Admin Area is the central control panel for administrators managing PanelAlpha Multi Server. From here you can monitor the dashboard, manage instances and services, control users, review logs, and oversee migrations end-to-end.

## Pages In This Section

- [Dashboard](dashboard.md) — Overview of the admin dashboard with widgets, activity graphs, and navigation
- [Instances](instances.md) — Manage all client WordPress instances and create new ones
- [Services](services.md) — Manage hosting services, domains, DNS zones, and accounts
- [Users](users.md) — Add and manage user accounts and control access permissions
- [Logs](logs.md) — Monitor activity, task, server, and diagnostic logs with filtering
- [Migrations](migrations.md) — Import WordPress sites with automatic or manual migration methods

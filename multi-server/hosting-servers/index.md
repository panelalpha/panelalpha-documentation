# Hosting Servers

PanelAlpha manages WordPress hosting across multiple backend servers from a single hub. This section describes each supported hosting scenario and how to connect cPanel, Plesk, DirectAdmin, PanelAlpha Engine, or WP Cloud to your platform.

## Pages In This Section

- [Hosting Scenarios](hosting-scenarios.md) — Overview of supported hosting integrations and deployment schemes
- [PanelAlpha Engine](engine.md) — Connect PanelAlpha Engine and configure plan limits and Redis caching
- [cPanel](cpanel.md) — Connect cPanel as a hosting server for shared hosting environments
- [Plesk](plesk.md) — Connect Plesk as a hosting server for shared hosting environments
- [DirectAdmin](directadmin.md) — Connect DirectAdmin as a hosting server for shared hosting environments
- [WP Cloud](wp-cloud.md) — Connect WP Cloud and manage resources from the PanelAlpha dashboard
- [Engine Server Management](../../panelalpha-engine/v1/server-management/index.md): manage a connected PanelAlpha Engine server (details, IPs, firewall, WAF, outgoing mail and notifications). The pages are in the Engine v1 documentation because Single Server uses the same screens.
